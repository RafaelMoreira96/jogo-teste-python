# =====================================================================
#  HISTÓRIA DO JOGO
#
#  Este arquivo é seu! Tudo abaixo é só um EXEMPLO mostrando os recursos.
#  Apague e escreva a sua história. As mudanças valem no próximo
#  "Novo jogo" (não precisa fechar o jogo).
#  Se algo estiver errado, o jogo mostra o erro e a linha na tela.
# ---------------------------------------------------------------------
#  COMO ESCREVER
#
#  === nome            começa um diálogo. O nome é usado no mapa
#                      (seção [npcs] de maps/mundo.txt) e nos @ir/@opcao.
#
#  Nome: texto         alguém fala. Texto longo quebra de linha sozinho.
#  texto               narração (sem nome na caixa).
#  - texto             narração mesmo que tenha ":" no meio.
#
#  @marcar algo        liga uma "marca" para o jogo lembrar que algo
#                      aconteceu (ex.: @marcar pegou_chave).
#  @desmarcar algo     desliga a marca.
#
#  @se algo            o que vem até o @fim só acontece se a marca
#    ...               estiver ligada. Use @se !algo para "se NÃO".
#  @senao              (opcional) o que acontece caso contrário.
#    ...
#  @fim
#
#  @opcao Texto -> outro_dialogo      escolhas para o jogador.
#  @opcao Outro texto -> mais_um      (coloque várias seguidas)
#
#  @ir outro_dialogo   continua em outro diálogo.
#  @curar              enche a vida do jogador.
#
#  DIREÇÃO DE CENAS E MOVIMENTOS (controle tudo por aqui!)
#  @mapa casa.txt [x y]             troca de mapa (opcional: posição x y).
#  @cenario normal|cidade|cidade_destruicao   muda para cutscene especial.
#  @clima dia|noite|chuva|trevas    muda a iluminação/clima na hora.
#  @clarao [branco|vermelho|roxo|dourado]     clarão dramático na tela.
#  @tremer [forca] [segundos]       treme a tela e vibra o controle.
#  @efeito poder|fogo|fumaca|explosao|parar [ator]   partículas no ator.
#  @pose <ator> dormir|acordar|assustar|comemorar|tremer|poder|caido
#  @olhar <ator> cima|baixo|esquerda|direita|<outro_ator>
#  @pular <ator>                    faz o personagem dar um pulo.
#  @emocao <ator> !|?|...|coracao   mostra balão de expressão na cabeça.
#  @mover <ator> <direcao> [passos] faz o personagem caminhar na cena.
#  @mover <ator> <x> <y>            caminha até a coordenada (x, y).
#  @posicionar <ator> <x> <y>       teleporta o ator para o tile (x, y).
#  @camera <ator>|<x y>             foca a câmera em alguém ou num ponto.
#  @esperar <segundos>              pausa o texto enquanto a cena acontece.
#  (Ator pode ser: heroi, o número do NPC no mapa como 1, ou seu diálogo como sabio)
#
#  DIÁLOGOS ESPECIAIS (rodam sozinhos)
#  inicio                 cena de abertura quando começa um Novo Jogo.
#  ao_slimes_derrotados   quando o último slime é derrotado
#                         (isso também liga a marca slimes_derrotados).
#
#  DICA: Aperte F2 no jogo para abrir o Editor Visual e F5 para recarregar
#  este arquivo ao vivo!
# =====================================================================
